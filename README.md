# Matchmaker Desk

Internal tool for The Date Crew matchmakers.
## Tech Stack:
- Express + TypeScript: Smallest Api
- Postgres + Prisma: Persistant i belive minimal
- Vercel serverless: Try to bypass a cold start
- Vite SPA: Minimal Frontend web page. 

## Setup
    cd api && pnpm install
    cp .env.example .env
    pnpm migrate
    pnpm dev
